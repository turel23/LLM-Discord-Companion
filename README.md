LLM powered discord bot that acts realistically
Some ideas to be implemented:
- Evolving relationships
- Forgetting curve and memory decay
- Spontaneous messaging
- Human-like messaging
- Voice messages and voicecalls

Trying to implement the Stanford smallville paper "Generative Agents: Interactive Simulacra of Human Behavior": https://arxiv.org/pdf/2304.03442

# Setting it up
You need a Discord bot, as well as your token and server Guild ID.
Clone it onto your local computer, and create a .env following the example. Install requirements.txt:
pip install > requirements.txt
Then run the code using
python main.py
